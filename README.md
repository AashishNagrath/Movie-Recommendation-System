# Movie Recommendation System

A content based movie recommendation system built in Python using NLP and cosine similarity.

I have built this just to test my basic knowledge of Data Science, and Model Training using Python

## Features

- Content-based filtering
- NLP preprocessing (stemming and vectorziation)
- Cosine similarity model
- Streamlit web interface
- TMDB API integration for movie postesr

## Tech Used

- Python
- Pandas
- Scikit-learn
- NLTK
- Streamlit
- TMDB API

## Basic Working

1. Movie metadata is processed.
2. Tags are created using overview, genres, keywords, cast, and director.
3. CountVectorizer converts text into vectors.
4. Cosine similarity calculates movie similarity.
5. Top 5 similar movies are displayed with posters.
